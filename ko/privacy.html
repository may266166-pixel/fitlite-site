FitLite 개인정보 처리방침

최종 업데이트: 2026년 5월 10일

FitLite는 오프라인 우선 피트니스 앱입니다. 개인정보를 수집하지 않습니다. 플랜·기록·체측 데이터·식사 로그는 모두 기기에만 저장됩니다. 본 방침은 앱이 다루는 모든 데이터 흐름을 명시하여 위험 판단을 돕습니다.

1. 수집하지 않는 항목

  • 이름·이메일·전화번호·Apple ID·위치·기기 고유 식별자 미수집
  • 플랜·기록·체중·식사·습관 시간을 어떤 서버에도 업로드 안 함
  • 계정 시스템 없음, 클라우드 동기화 없음
  • 제3자 분석 플랫폼(Firebase Analytics 등)에 이벤트 전송 안 함

2. 기기 로컬 데이터

FitLite는 다음을 iOS 앱 샌드박스(AsyncStorage / SecureStore)에 저장하며 본인만 접근 가능합니다:

  • 프로필: 성별·나이·키·체중·목표·수준
  • 훈련 플랜과 기록
  • 매일 음수·식사·근육통 로그
  • 로컬 알림 스케줄
  • 구독·팁의 로컬 캐시(결제 정보 미포함)

앱 삭제 시 함께 사라집니다. 설정의 "모든 데이터 삭제"로 수동 삭제도 가능합니다.

3. 코치 채팅(선택 기능)

"코치" 탭은 Google Gemini를 우선 사용하며 다음 순으로 폴백합니다:

  • 주 경로: 빌드에 Gemini API 키가 설정되고 네트워크가 사용 가능할 때, 입력 텍스트가 Google 서버로 전송되어 답변이 생성됩니다. 이름·기기 ID·Apple ID 등 미동반. Google API 정책: ai.google.dev/gemini-api/terms
  • 시스템 폴백(iOS 26+): Gemini 사용 불가 시 Apple Intelligence Foundation Models 프레임워크 호출. 추론은 전적으로 기기에서, 입력과 출력 모두 기기를 떠나지 않습니다.
  • 최종 폴백: 위 두 계층 모두 사용 불가 시 기기 내 규칙 엔진이 키워드 기반 템플릿 답변. 완전 오프라인.

세 계층 모두 운동 기록·체중·식사 로그를 업로드하지 않습니다.

4. 광고(무료 버전만)

무료 사용자는 휴식 중 Google AdMob 배너 광고를 봅니다. SDK 데이터 범위:

  • iOS의 ATT 대화상자에서 "추적 허용"을 선택해야만 AdMob이 IDFA를 개인화에 사용
  • "추적 안 함" 선택 시 비개인화 광고로 전환되며 IDFA 미사용
  • SKAdNetwork(Apple의 개인정보 보호 어트리뷰션)는 개인정보 없는 설치/전환 보고를 한 번 전송
  • AdMob 정책: policies.google.com/privacy

"광고 제거" 구독으로 모든 광고 SDK 호출 중지.

5. 인앱 결제

모든 팁과 구독은 Apple App Store IAP를 통합니다. FitLite는 결제 정보에 닿지 않으며 Apple로부터 "유효 구독 보유 / 팁 완료" 불리언 신호만 받아 로컬에 저장합니다.

  • 구독은 만료 24시간 전 현 가격으로 자동 갱신
  • 설정 › Apple ID › 구독에서 언제든 취소 가능
  • 환불은 Apple 처리: reportaproblem.apple.com

6. 건강 데이터(선택 기능)

"오늘 소모" 카드는 iOS 건강에서 오늘의 걸음 수를 읽어 걷기 에너지를 추정할 수 있습니다.

  • "건강 동기화" 탭 후 시스템 권한 부여 시에만 걸음 수 읽음
  • 읽기 범위는 오늘 걸음 수만. 심박·수면·체중 등 다른 카테고리 미접근
  • FitLite는 건강에 쓰지 않으며 걸음 수를 서버에 업로드하지 않습니다
  • 걸음 수는 운동 기록과 동일한 샌드박스에만 저장
  • 이 기능을 안 써도 수동 입력으로 충분. 건강 권한 없이도 정상 동작

7. 알림

훈련 알림은 전적으로 기기 내에서 iOS 알림 시스템을 통해 전달됩니다. FitLite에는 푸시 서버가 없으며 마케팅 알림도 보내지 않습니다.

8. 앱 업데이트 확인

실행 시(및 "설정 › 업데이트 확인" 수동 실행 시) Apple의 itunes.apple.com/lookup 엔드포인트로 HTTPS 요청을 한 번 보냅니다. Bundle ID(com.fitai.dw.app)만 전달하여 App Store 현재 게시 버전을 조회합니다. 사용자 식별자 미동반, 수신자도 Apple 자체 서비스입니다.

9. 어린이 개인정보

FitLite는 13세 미만 어린이를 대상으로 하지 않습니다. 어린이 정보를 의도적으로 수집하지 않습니다. 보호자 동의 없이 어린이가 사용 중이라고 생각되면 연락 주십시오. 로컬 데이터를 삭제합니다.

10. 정책 변경

본 정책 업데이트 시 상단 "최종 업데이트" 일자가 변경됩니다. 중대 변경(업로드 항목 추가 등)은 앱 내에서도 눈에 띄게 안내합니다.
