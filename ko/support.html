FAQ

플랜이 안 맞아 / 재생성하고 싶다

설정 › 계정 › 플랜 재생성. 현재 플랜은 덮어쓰지만 운동 기록은 보존됩니다.

동작이 너무 어렵거나 쉬워요

운동 화면에서 동작 우상단 "교체" 버튼으로 같은 근육군의 다른 난이도 동작을 추천받을 수 있습니다. 길게 누르면 상세에서 세트/회수 조정도 가능.

구독 취소 방법

  • iPhone: 설정 앱 › 상단 Apple ID › 구독 › FitLite Premium › 취소
  • 취소 후 현 기간은 유효, 다음 기간부터 청구 안 됨
  • 이미 청구된 환불은 reportaproblem.apple.com에서 Apple에 신청

기기 변경 / 재설치 후 구독이 사라졌어요

FitLite 설정 페이지 하단의 "구매 복원"을 탭하세요. 같은 Apple ID라면 한 번 탭으로 구독 상태가 복원됩니다.

모든 데이터를 지우고 싶어요

설정 › 계정 › 모든 데이터 삭제. 플랜·기록·프로필·식사·근육통 로그·습관 시간 분석을 일괄 삭제. 구독 상태는 Apple 관리이므로 영향 없음.

데이터가 클라우드로 가나요?

가지 않습니다. FitLite는 서버가 없고 모든 것이 iPhone 샌드박스에 있습니다. 삭제 시 완전 제거. 자세히는 개인정보 처리방침.

알림이 안 와요

  • 설정 앱 › 알림 › FitLite 허용 여부 확인
  • "집중 모드"는 비허용 알림을 음소거. FitLite를 허용 목록에 두세요
  • FitLite 설정 › 알림 › 테스트 알림으로 스케줄 동작 확인

휴식 중 광고가 너무 많아요

무료 버전은 동작 3개마다 배너를 1번 표시합니다. 거슬리면 "광고 제거" 구독(설정 › 광고 제거)을 구독해 주세요. 구독 기간 광고가 모두 꺼집니다.
