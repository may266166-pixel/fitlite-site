FAQ

Plan ne convient pas / régénérer

Réglages › Compte › Régénérer le plan. Écrase le plan actuel mais conserve l'historique.

Exercices trop durs ou faciles

Sur l'écran d'entraînement, touche « Échanger » près d'un exercice pour une alternative du même groupe musculaire avec une autre difficulté. Appui long ouvre les détails pour ajuster séries/reps.

Comment annuler l'abonnement

  • iPhone : Réglages › haut Apple ID › Abonnements › FitLite Premium › Annuler
  • La période en cours reste active après annulation ; la suivante n'est pas facturée
  • Pour rembourser une période déjà facturée, demande via reportaproblem.apple.com

Changement d'appareil / réinstallation : abonnement disparu

En bas des Réglages FitLite, « Restaurer les achats ». Avec le même Apple ID, un tap restaure.

Effacer toutes les données

Réglages › Compte › Effacer toutes les données. Supprime plan, journaux, profil, repas, courbatures, analyse d'horaires. L'abonnement reste géré par Apple, non affecté.

Les données vont-elles dans le cloud ?

Non. FitLite n'a pas de serveur ; tout reste dans le sandbox iOS. La désinstallation supprime tout. Voir la Politique de confidentialité.

Pas de rappels

  • Vérifie Réglages › Notifications › FitLite autorisé
  • « Concentration » coupe les notifications non autorisées — inclus FitLite dans la liste
  • FitLite Réglages › Rappels › Envoyer un rappel test pour vérifier la planification

Trop de pubs aux pauses

La version gratuite affiche une bannière toutes les 3 exercices. Si ça gêne, abonne-toi à « Sans pub » (Réglages › Sans pub) — toutes les pubs s'éteignent.
